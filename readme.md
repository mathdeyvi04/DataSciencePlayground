# Descrição

Este repositório será usado para armazenar `.ipynb`, os quais armazenam código e resultados de análises,
apesar de não serem capazes de guardar os dados referentes à notebook.

Como dentro dos arquivos é possível escrevermos em `Markdown`, acredito que não seja necessário uma pasta
separada para cada um, contendo respectivos readme.md e outros.
